# Documentation Index

Docs are grouped by stable product/system area:

- `project/` — product requirements, architecture, build/release process, modules, and localization.
- `changelog/` — pending release notes, changelog workflow, and per-version archives.
- `agent-runtime/` — agent readiness, prompt injection, rate limits, tmux/Ghostty/session behavior, and terminal runtime details.
- `app-ui/` — AppKit user-facing behavior such as sidebar, status bar, changes panel, windows, banners, settings, and update UI.
- `cli/` — Magent CLI reference and interactive CLI behavior.
- `git-worktrees/` — worktree, branch-tracking, and local file sync behavior.

When adding a doc, prefer an existing category. Create a new top-level docs category only when several related docs need a distinct home.
